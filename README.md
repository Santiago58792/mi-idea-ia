# Riego inteligente para agricultores de Enguera

## Resumen 
Mi idea es crear una IA para ayudar a los agricultores de Enguera y la zona de Valencia a optimizar el riego y detectar enfermedades en olivos y viñas. Usa fotos de las hojas y datos del tiempo para avisar cuando regar.

El sistema usará fotos del tiempo para avisar cuándo regar y si una planta está enferma, reduciendo el gasto de agua y mejorando la cosecha. 

## Origen
Vivo en Enguera, es una zona agrícola donde el agua es muy importante y muchos vecinos tienen campos pequeños y no tienen tecnología cara.

## Funcionamiento
1. El usuario hace una foto a la hoja. 
2. La app la analiza con visión por computador y la combina con la previsión del tiempo. 
3. Da una recomendación simple: regar, no regar, o revisar la planta.

##Datos necesarios
 * Fotos de hojas de olivo y viña (sanas y enfermas9.
 * Datos de temperatura y lluvia de AEMET / OpenWeather.
 * Información básica del tipo de suelo.

## Beneficio
Ahorro de agua, detección temprana de enfermedades y mejora de la cosecha para pequeños agricultores.
