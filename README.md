# Riego inteligente para agricultores de Enguera

## Resumen
Mi idea es crear una IA para ayudar a los agricultores de Enguera y la zona de Valencia a optimizar el riego y detectar 
enfermedades en olivos y viñas.
El sistema usara fotos de las hojas y datos del tiempo para avisar de cuando regar y si una planta está enferma, reduciendo el gasto de agua y mejorando la cosecha.

## Origen
Vivo en Enguera, una zona agrícola donde el agua es muy importante y muchos vecinos tienen campos pequeños y no tienen acceso a tecnología cara.

## Funcionamiento
1. El usuario hace una foto a la hoja con el móvil.
2. La app la analiza con visión por computador y la combina con la previsión del tiempo.
3. Da una recomendación simple: regar, no regar, o revisar la planta.
